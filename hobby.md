# Мой пет-проект

Идея: телеграм-бот для учёта личных расходов — записываешь трату сообщением («300 продукты»), бот сам раскидывает по категориям и раз в неделю присылает сводку.

Стек: Python, aiogram, SQLite

Цель: научиться работать с Telegram Bot API, спроектировать простую базу данных и задеплоить бота на сервер.
