# IDE vs CLI: заметки

## Что удобно в VS Code

1. Визуальный diff — сразу видно, какие строки добавлены, а какие удалены, 
   с подсветкой прямо в редакторе, без чтения текстового вывода в терминале.

2. Панель Source Control — весь статус файлов (staged/unstaged/untracked) 
   виден одним взглядом, не нужно постоянно набирать git status.

3. История коммитов и GitLens — можно кликнуть на любую строку кода и 
   сразу увидеть, кто и когда её изменил (git blame), без ручного поиска 
   по git log.

## Что удобнее делать в терминале

Сложные операции вроде rebase -i, cherry-pick и разрешение конфликтов 
при мерже — в терминале виден точный вывод команд и легче контролировать 
каждый шаг, тогда как IDE иногда скрывает детали процесса за упрощённым 
интерфейсом.
